Tampermonkey userscript that hides videos with visible watch progress on YouTube Home and channel pages, including partially watched videos. Videos inside playlists are excluded.

Install [Tampermonkey](https://www.tampermonkey.net/), open the [userscript](https://raw.githubusercontent.com/sashokey/hide-youtube-watched-videos/master/hide-youtube-watched-videos.user.js), and confirm installation. Reload YouTube.

Watched videos are hidden by default. Use the eye-icon toggle in YouTube's account menu to show them again. The preference is saved and synchronized across tabs.
